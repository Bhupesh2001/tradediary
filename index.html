Import Trades from JSON
Ask your broker's AI for your trades in the TradeDiary JSON format, paste the result here, then add emotion, stop-loss and notes before saving.
JSON format reference
Required: symbol, side (BUY/SELL = opening order), quantity, entryPrice, exitPrice, date (YYYY-MM-DD)
Recommended: instrument (EQUITY/OPTION/FUTURE), optionType (CE/PE), entryTime, exitTime (HH:MM, 24h)
Optional: product (INTRADAY/DELIVERY), charges, grossPnl (cross-check), tradeId (duplicate detection)
Direction is automatic: Buy first → Long, Sell first → Short (a bought CE or PE is Long). Compare Calls vs Puts and Bullish vs Bearish in Analytics.
